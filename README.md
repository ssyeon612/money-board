# Money Board

Google Sheets를 읽어 표시하는 개인 자산 대시보드입니다.

## 로컬 실행

### Netlify에 등록한 설정으로 실행

`npm run dev:netlify` 실행 후 http://localhost:8888 에 접속합니다.
Netlify Dev가 연결된 사이트의 Production 환경 변수를 메모리로 가져와 로컬 함수를 실행합니다. 인증 정보를 `.env`에 복사할 필요가 없습니다.

최초 실행 환경에서는 `npx --yes netlify-cli login` 후 `npx --yes netlify-cli link --id b27d77d5-807a-4155-9929-2d2a8a7e38e6`로 연결합니다. 로그인과 인터넷 연결이 필요합니다. 사이트 연결 정보는 Git에서 제외된 `.netlify`에 저장됩니다.

HTML 수정 후에는 서버를 다시 실행하면 빌드한 화면에 반영됩니다. 이 명령은 로컬 실행만 하며 사이트를 배포하지 않습니다.

### 별도 로컬 환경 변수로 실행

`npm run dev` 실행 후 http://localhost:8080 에 접속합니다. HTML과 데이터 API를 함께 제공합니다.
실제 시트 조회에는 `.env` 파일에 `GOOGLE_SERVICE_ACCOUNT_JSON`과 `GOOGLE_SPREADSHEET_ID`를 설정해야 합니다. `.env`는 Git에서 제외됩니다.

## Netlify 배포

- Git 저장소를 연결해 배포합니다. HTML 파일만 드래그해서 배포하면 서버 함수가 동작하지 않습니다.
- 빌드 명령: `npm run build`, 공개 폴더: `public`, 함수 폴더: `netlify/functions` (`netlify.toml`에 설정).
- Node.js 22 이상을 사용합니다.
- Production 환경 변수 `GOOGLE_SERVICE_ACCOUNT_JSON`에 서비스 계정 JSON 전체를, `GOOGLE_SPREADSHEET_ID`에 시트 ID를 등록합니다. Scope를 지정한다면 Functions를 포함합니다.
- Google Sheets API를 활성화하고 해당 서비스 계정에 시트 뷰어 권한을 줍니다.
- 환경 변수 변경 후에는 새로 배포합니다. 키 파일이나 환경 변수 값을 Git에 넣지 마세요.

## 동작 확인

1. 새 코드로 배포한 사이트에 접속합니다.
2. ‘구글 시트 연결됨’과 ‘마지막 조회’ 시각을 확인합니다.
3. 실패하면 화면의 오류와 Netlify Functions의 `assets` 로그를 확인합니다. 인증 정보와 시트 내용은 로그에 출력하지 않습니다.
4. 시트의 금액을 수정한 뒤 페이지에서 새로고침 버튼을 누르거나 1분을 기다립니다.

시트를 편집할 때마다 재배포할 필요는 없습니다. 열린 화면은 1분마다 조회하며 숨겨진 탭은 일시 중지합니다. 조회 실패 시 기존 값을 유지하며 실패 상태를 표시합니다.

## 시트 구조

- `자산현황`: A:F, `자산분류`와 `부채분류` 제목 및 개별 항목을 사용합니다. 금액은 D열, 유동성은 F열(`유동자산`/`비유동자산`)입니다.
- `투자 종목`: A:L, `종목코드/티커` 아래의 항목과 `총 매수금액(원)`, `총 평가금액(원)`, `USD/KRW` 요약을 사용합니다.
- `월별 자산 추이`: A:F, `기준월` 아래에서 총자산이 입력된 행만 표시합니다. 기준월은 `YYYY-MM` 텍스트입니다.
- 각 탭의 첫 5,000행을 읽습니다. 제목과 열 배치를 유지하면 새 항목도 반영됩니다.
- 총자산, 부채, 순자산, 자산 구성, 유동성은 개별 항목에서 계산합니다. 시트 합계 수식이 새 행을 누락해도 페이지는 새 항목을 포함합니다. 월별 기록은 원본 값을 유지합니다.

## 검증

`npm ci`, `npm test`, `npm run build` 순서로 실행합니다.

## 접근 범위

Google 인증 정보는 서버 함수에서만 사용됩니다. 현재 페이지와 조회 API에는 사용자 인증이 없으므로 사이트 방문자는 표시되는 자산 정보를 조회할 수 있습니다. 개인 전용 접근 제한은 별도 설정이 필요합니다.
